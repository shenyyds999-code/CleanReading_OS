# WebView 程序生成器 — 设计方案

> 一个**开源跨平台工具**：输入服务器地址（URL），一键生成三种端口的独立安装包
> - 🖥️ **Windows 桌面端 (.exe)** — 查书电脑
> - 📱 **安卓触屏端 (.apk)** — 借书机（扫码枪适配）
> - 📱 **安卓手机端 (.apk)** — 校外手机访问

> 版本：v0.1-draft ｜ 技术底座：Node.js + Capacitor ｜ 许可证：MIT（草案）

---

## 1. 产品定位

**不是**给某个系统定制，而是**通用工具**：任何 Web 应用，填个网址就能打包成桌面 + 移动安装包。

- 第一实际用例 = CleanReading OS 图书馆系统
- 核心交互：`输入 URL → 选平台 → 点"生成" → 输出安装包`
- 开源发布，别人下载后在自己的电脑上跑，即可为自己的网站/系统打包

## 2. 为什么选 Capacitor（技术选型论证）

### 2.1 核心诉求 → 选型约束
| 诉求 | 约束 |
|------|------|
| 开源、给别人用 | 必须**跨平台**（Win/Mac/Linux 都能跑） |
| 一个即可产 exe + apk | 单一技术栈同时覆盖桌面 + 移动 |
| 简单、同学生态成熟 | 资料多、好查、维护成本低 |
| 尽量复用 Web 前端 | 不重写现有 H5 |

### 2.2 方案对比
| 方案 | 桌面 exe | 安卓 apk | 单一栈 | 上手难度 | 结论 |
|------|:-------:|:-------:|:------:|:--------:|:----:|
| **Capacitor** | ✅ (via Electron/NW) | ✅ | ✅ | 低 | ⭐ **推荐** |
| Electron 全包 | ✅ | ❌ | - | 中 | 只做桌面 |
| 原生 Android | ❌ | ✅ | - | 高 | 只做移动 |
| Tauri | ✅ | ❌ | - | 高 | 需 Rust |
| PWA | 无安装包 | 无安装包 | - | 低 | 作为附加捷径 |

**结论**：以 **Node.js + Capacitor** 为统一技术底座。Capacitor 生态有：
- `@capacitor/core` + `@capacitor/android` → 安卓 apk
- 桌面端通过 **NW.js / Electron 壳** 加载同一套 Web 资源 → exe

### 2.3 为什么不是纯 Electron / 纯原生
- **纯 Electron**：可以出 exe，但 apk 还是要另搞一套原生 → 维护两套代码
- **原生 Android**：出 apk 很顺，但 exe 又得另起炉灶
- Capacitor 让**同一份 webview 代码被多个平台复用**，一个生成器脚本两处调用，最省心

## 4. 三端实现细节

### 4.1 Windows 桌面端 (.exe) — 供查书电脑
- **技术**：Electron 或 NW.js 壳 + Capacitor Web 资源
- **打包**：`electron-builder` → 单文件 .exe
- **体验**：
  - 全屏/可配置窗口，隐藏地址栏，纯应用感
  - 启动即加载用户填的 URL（默认指向系统查书客户端 `/client/`）
  - 可定"应用名、图标、窗口尺寸"
- **适合**：旧电脑（性能要求低，Electron 可调）

### 4.2 安卓触屏端 (.apk) — 借书机
- **技术**：Capacitor → Android
- **关键**：**原生 WebView 默认聚焦到 `#isbnInput`**，保持扫码枪适配不失效
  - 你系统里 `inputmode="none"` + 回车自动搜索 + 拼音软键盘，纯 WebView 就能正常工作
  - 禁用安卓软键盘弹出（扫码枪场景）
- **体验**：全屏沉浸、触屏优化、禁用浏览器回退/缩放手势、防止休眠
- **打包**：Gradle 出 .apk

### 4.3 安卓手机端 (.apk) — 校外手机
- **技术**：Capacitor → Android（与借书机壳复用，仅 Web 地址/图标/名称不同）
- **体验**：普通 WebView + 状态栏、登录态持久化（Cookie/JWT 本地存储）、可能的推送（后续）
- **可选捷径**：同时发布 **PWA**（加到主屏幕，免安装），作为轻量补充

## 9. 风险与注意

| 风险 | 说明 | 对策 |
|------|------|------|
| **打包环境复杂** | apk 要 Android SDK+JDK+Gradle，exe 要 Windows | 文档写清"环境准备"；提供一键环境检查脚本 |
| **生成器自身打包** | 生成器本身也要做成可分发 exe | 用 electron-builder 出生成器的安装包 |
| **旧电脑性能** | Electron 壳较重 | 提供"轻量模式"(NW.js/pywebview 可选) |
| **URL 变更** | 服务器地址写死进壳 | 预留"设置页/配置文件"可改地址，或支持多地址 |
| **证书/签名** | 安卓默认无签名，装机会提示 | 文档说明自签名 + 侧载安装步骤 |
